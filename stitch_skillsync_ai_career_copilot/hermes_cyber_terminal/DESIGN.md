## Brand & Style

This design system channels an uncompromising retro-futuristic, technical brutalist aesthetic tailored for advanced artificial intelligence agents, autonomous researchers, and high-velocity engineers. Rooted in command-line terminal elegance and high-spec telemetric instrumentation, the interface prioritizes hyper-dense information architecture, mechanical clarity, and ambient cybernetic depth.

### Visual Philosophy
- **Aesthetic Movement:** Technical Neo-Brutalism fused with Phosphor Cyber-Terminal. It balances vintage CRT data displays with razor-sharp modern typography.
- **Atmosphere:** Deep near-black obsidian substrates, punctuated by electric phosphor accents, subtle luminous reticle lines, and structured telemetry matrices.
- **Emotional Resonance:** Sovereign, analytical, clandestine, hyper-capable, and razor-sharp. The experience feels like piloting an autonomous intelligence mainframe rather than browsing standard web software.
- **Target Audience:** Autonomous AI researchers, systems programmers, cryptography specialists, and developer-first power users demanding extreme clarity and zero ornamental fluff.

## Colors

The color architecture is built strictly for high-contrast dark environments. Pure blacks are anchored with deep obsidian slate, allowing stark, high-luminance primary pigments to deliver tactical focal points.

### Palette Architecture
- **Obsidian Substrates (`#050507`, `#0A0A0C`, `#121216`):** Deep, light-absorbing foundations designed to suppress optical fatigue while rendering glowing telemetry accents with razor fidelity.
- **Pure Electric Blue (`#0000F2`):** The signature primary engine hue derived from the original brand identity. Used deliberately for authoritative primary calls-to-action, key telemetry milestones, active command prompts, and high-frequency beacons.
- **Cyber Amber (`#FF5500`):** An urgent secondary accent invoking vintage CRT amber terminals and warning triggers. Used for volatile operations, real-time token streams, and critical state toggles.
- **Phosphor Green (`#00FF88`):** A tertiary nod to classic matrix screens and operational health metrics. Indicates online daemon status, low latency, and verified cryptographic proofs.
- **Bone White (`#ECEBE6`):** The primary typographic ink. Replaces harsh `#FFFFFF` to reduce eye strain over prolonged multi-screen operational cycles while maintaining peak legibility against obsidian surfaces.
- **Structural Gray Grid (`#1F2029`, `#3B3D4D`):** Crisp 1px division lines providing the structural chassis for all windows, split panes, and telemetry readouts.

## Typography

The typographic hierarchy fuses the brutalist condensed authority of condensed grotesques with the mathematical precision of fixed-pitch monospaced fonts.

### Hierarchical Roles
- **Headlines & Primary Metrics (`Space Grotesk`):** Engineered for compact high-contrast impact. Tight negative letter-spacing (`-0.02em` to `-0.04em`) delivers commanding presence in section dividers, modal headers, and main system statements.
- **Narrative & System Logs (`Space Mono`):** Used for analytical copy, interactive command dialogues, system descriptions, and model output. Maintains strict horizontal cadence to simulate raw console output while preserving prose readability.
- **Metadata, Badges & Micro-Telemetry (`JetBrains Mono`):** Designed for extreme high-density UI zones—latency indicators, token counters, memory maps, system architecture trees, and code blocks.
- **Styling Directives:** All labels and badges leverage uppercase casing (`text-transform: uppercase`) paired with wide tracking (`0.08em` to `0.12em`) to mirror aerospace avionics and command-line interfaces.

## Layout & Spacing

Layouts follow a modular, technical grid system inspired by multi-pane terminal multiplexers (tmux/vim) and financial terminal displays.

### Layout Philosophy
- **Modular Fluid Grid:** Layouts are structured across a 12-column dynamic grid with zero excess padding. Containers touch and share 1px high-precision borders to form contiguous command panels.
- **Information Density:** Spacing favors compact, actionable layouts. Dense spacing tokens (`space-xs` and `space-sm`) dominate data visualization, metric cards, and toolbars, reserving expansive space (`space-xl`) strictly for terminal canvas margins.
- **Viewport Adaptation:**
  - **Desktop (≥1024px):** Multi-pane split layouts featuring an inspector sidebar (280px-320px fixed), central streaming log, and top persistent telemetric status ribbon.
  - **Tablet (768px - 1023px):** Collapsible command drawer with persistent main terminal view; gutters step down to `1rem`.
  - **Mobile (<768px):** Single-column stacked panes. Lateral canvas margins compress to `1.25rem`. Heavy tables and raw JSON logs reflow into horizontal scroll strips with sticky command action bars.

## Elevation & Depth

This design system avoids soft, organic drop shadows, replacing them with sharp tonal layering, crisp borders, and subtle phosphor luminescence.

### Depth Architecture
1. **Backdrop Void (Level 0):** `#050507`. Background canvas featuring an ultra-subtle SVG reticle grid (e.g., 24px x 24px grid lines rendered at `#1F2029` with 35% opacity).
2. **Substrate Panels (Level 1):** `#0A0A0C` bounded by 1px solid `#1F2029` borders. Panels join edge-to-edge with no drop shadows, creating a unified flight-deck or workbench structure.
3. **Elevated Drawers & Flyouts (Level 2):** `#121216` with a crisp 1px `#3B3D4D` border and an ambient, directional technical drop: `0px 4px 0px rgba(0, 0, 0, 0.8)`.
4. **Active Modals & Critical Overlays (Level 3):** `#181820` with a sharp border and an electric phosphor halo: `0 0 24px rgba(0, 0, 242, 0.25)`.
5. **Interactive Glow & Focus Rings:** Interactive triggers reject blurred rings. Focus states employ a dual-stroke effect: `box-shadow: 0 0 0 1px #050507, 0 0 0 2px #0000F2`, occasionally accented with a subtle amber terminal flash upon command execution.

## Shapes

The design system operates primarily with sharp and restrained soft geometries, rejecting soft, pillowy consumer corners in favor of technical apparatus styling.

### Shape Geometry
- **Default Elements (`roundedness: 1`):** Buttons, input panels, card containers, and dropdowns use a maximum radius of `0.25rem` (4px). This soft bevel prevents visual brittleness while maintaining mechanical authority.
- **Pill Badges (`rounded-full`):** Reserved exclusively for micro-telemetry pills (e.g., model version badges, `RUNNING` status orbs, protocol tags).
- **Hard Technical Notches:** Selected primary system blocks and command prompts may feature chamfered 45-degree corner clips (`clip-path: polygon(...)`) to intensify military-grade workstation vibes.
- **Line Accents:** Structural dividers are strictly 1px wide, maintaining uncompromising vector crispness across retina screens.

## Components

### Buttons & Command Triggers
- **Primary Action (Hyper-Electric):** Background `#0000F2`, text `#ECEBE6`, 1px solid `#0000F2`. Hover triggers a subtle phosphor bloom `box-shadow: 0 0 12px rgba(0, 0, 242, 0.6)` with rapid 100ms transition. Active state shifts background to `#0000B8`.
- **Secondary / Ghost Button:** Background `transparent`, border 1px solid `#3B3D4D`, text `#ECEBE6`. Hover activates background `#121216` and border `#ECEBE6`.
- **Destructive / Abort Button:** Background `rgba(255, 85, 0, 0.1)`, border 1px solid `#FF5500`, text `#FF5500`. Hover delivers `#FF5500` fill with `#050507` typography.
- **Terminal Key Caps:** Tiny monospaced shortcut triggers (e.g., `⌘K`, `ESC`) rendered with `#121216` background, 1px solid `#3B3D4D` border, and `4px` padding.

### Chips & Pill Badges
- **Status Indicator Pill:** Border radius `9999px`, padding `2px 8px`, typography `badge-caps`.
  - *Active Daemon:* `#0A0A0C` background, border `rgba(0, 255, 136, 0.3)`, text `#00FF88` with a pulsing 6px neon orb.
  - *Warning / Volatile:* Border `rgba(255, 85, 0, 0.4)`, text `#FF5500`.
- **Technical Tag:** Angular shape (`0.25rem` radius), `#121216` fill, `JetBrains Mono` 10px uppercase, framed in `#1F2029`.

### Input Fields & Prompts
- **Terminal Command Input:** Styled as a classic interactive command line. Left adornment features an electric blue or cyber amber chevron `>_`.
- **Field Styling:** Background `#0A0A0C`, border 1px solid `#1F2029`, font `Space Mono` 13px, text `#ECEBE6`, caret color `#FF5500`.
- **Focus State:** 1px solid `#0000F2` border accompanied by an ultra-crisp ambient border glow.

### Lists & Telemetry Logs
- **Log Stream Rows:** Border-bottom 1px solid `#181820`, alternating hover highlights (`#0E0E12`).
- **Data Columns:** Explicit monospaced time-stamp column in `#555660`, followed by level badge (`[INFO]`, `[AGENT]`, `[ERROR]`), ending in continuous bone-white log text.

### Selection Controls (Checkboxes & Radios)
- **Checkboxes:** Squared 14px boxes with a 1px solid `#3B3D4D` border and 1px radius. Checked state displays `#0000F2` solid background with an inverted bone-white checkmark.
- **Radio Buttons:** Circular 14px ring with an inner glowing dot of `#0000F2` or `#FF5500`.

### Cards & Telemetric Modules
- **Modular Data Cells:** Bound by a unified 1px `#1F2029` border. Each card features an optional header bar with monospaced breadcrumbs and active system metrics (e.g., `SYS.MEM // 42.1%`).
- **Corner Marks:** Critical overview cards use bracketed corner reticles (crosshairs or `+` characters at grid intersections) to reinforce avionics-grade telemetry.
